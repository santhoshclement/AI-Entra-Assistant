Project Overview

AI-Entra-Assistant is a portfolio project that demonstrates how Azure OpenAI, Microsoft Graph API, and Microsoft Entra ID can be combined to simplify identity administration, reporting, access reviews, and security governance.

Problem Statement

Identity teams spend significant time answering repetitive operational questions: inactive users, privileged roles, license usage, guest accounts, MFA status, and access review preparation.

Solution

This assistant allows administrators to ask natural language questions and receive identity insights powered by AI and Microsoft Graph API.

Sample AI Prompts

Show inactive users for the last 90 days
List all Global Administrators
Find guest users in the tenant
Generate license usage summary
Show users without MFA registration
Review privileged access assignments

Architecture

User → Web UI → Backend API → Azure OpenAI → Microsoft Graph API → Microsoft Entra ID

Core Features

Identity Reporting

Generate user, group, role, and license reports from Microsoft Graph API.

Privileged Access Review

Identify privileged role assignments and risky admin accounts.

Security Insights

Detect inactive accounts, guest users, and missing security controls.

AI Summary

Convert raw Graph API output into readable recommendations.
