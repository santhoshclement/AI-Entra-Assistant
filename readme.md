# AI-Entra-Assistant

AI-powered Identity Operations Assistant for Microsoft Entra ID.

## Overview

AI-Entra-Assistant demonstrates how Azure OpenAI and Microsoft Graph API can be used to simplify identity administration, reporting, access review, and security governance.

## Key Features

- Natural language identity queries
- Microsoft Graph API integration
- Privileged role reporting
- Inactive user detection
- Guest user review
- License reporting
- AI-generated security recommendations

## Architecture

User → Web UI → Backend API → Azure OpenAI → Microsoft Graph API → Microsoft Entra ID

## Technologies

- Azure OpenAI
- Microsoft Graph API
- Microsoft Entra ID
- Python
- FastAPI
- GitHub Pages
- Identity Governance

## Sample Prompts

- Show inactive users for 90 days
- List Global Administrators
- Find guest users
- Generate license report
- Review privileged access assignments
